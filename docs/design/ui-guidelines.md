# 界面设计规范

本文记录网站当前的视觉和交互约定。每一条都标出了**作为基准的代码文件**，内容已对照代码 `fa643541` 核对过。

新做页面或修改页面时，先找到对应的基准组件，直接复用；没有合适的，再参照基准的写法来做。不要另起一套新样式。

文中的组件路径都相对于 `apps/web/components/`。

---

## 一、整体风格

网站是"手账 / 纸片"风格：米黄色的纸张底色、手绘感的深色描边、手写体标题，配色以墨绿为主。

### 1. 主题色与 token

主题统一在 `providers.tsx` 的 `artzooTheme` 中设置（AntD `ConfigProvider`）。写样式时只用 token 或 CSS 变量，**不要直接写颜色值**。

| 用途 | 值 | AntD token |
|---|---|---|
| 主色 | #436B4E（悬停 #34583F，按下 #25432F） | `colorPrimary` |
| 标题文字 | #254B38 | `colorTextHeading` |
| 正文文字 | #24372B | `colorText` |
| 次要文字 | #58614F | `colorTextSecondary` |
| 边框 | #78816A；次要边框和分割线 #C5C9B1 | `colorBorder` / `colorBorderSecondary` |
| 卡片和弹层背景 | #FFFDF4 | `colorBgContainer` / `colorBgElevated` |
| 页面背景 | #FAF2DF | `colorBgLayout` |
| 成功 | #326846 | `colorSuccess` |
| 警示 | #79561A | `colorWarning` |
| 危险 | #A34335 | `colorError` |
| 信息 | #315F67 | `colorInfo` |

其他基础设置：

- 字号 16，行高 26。
- 圆角 12。
- 控件高度 40。
- 阴影统一使用很淡的墨绿色：`rgba(37,75,56,.1)` 到 `rgba(37,75,56,.18)`。

`app/globals.css` 中定义了一组 CSS 变量：`--artzoo-page`、`--artzoo-heading`、`--artzoo-text`、`--artzoo-secondary`、`--artzoo-primary`、`--artzoo-line`、`--artzoo-surface`、`--artzoo-fill`、`--artzoo-body-font`。在不方便使用 AntD token 的地方，用这些变量。

### 2. 字体

所有字体都放在本站服务器上（`public/artzoo/fonts/`），不使用外部字体服务。

- **正文**：英文和数字用 Patrick Hand，中文用 Xiaolai。Xiaolai 按字符范围拆成多个小文件，浏览器只下载页面上实际用到的那部分。
- **页面大标题**：DymonShouXieTi，只用于 `.page-heading` 中的 H1 和 H2。
  - H1：48/50，白色描边 10px。
  - H2：32/42，白色描边 8px。
  - 组件位置：`page-heading.tsx`。

字体加载列表在 `apps/web/static-assets.json` 中，由 `app/layout.tsx` 注入页面。

### 3. 纸张卡片与背景

纸张卡片的样式在 `app/globals.css`：

- `.paper-panel` 用九宫格切图（`border-image`）画出手绘描边，底下再叠一层平铺的纸纹。
- 活动卡和日常卡使用 `daily-paper.png`，心愿卡使用 `wish-paper.png`。
- 页面背景是低透明度的纸纹和小动物插图。

图片资源统一在 `app/static-assets.css` 中通过 `--artzoo-bg-*` 变量引用。这些文件名里带有哈希值，由构建脚本生成，不要手工修改。

### 4. 页面骨架

- 站点外框：`site-shell.tsx`，包含"跳到正文"链接、公告条、顶栏（`site-header.tsx`）和右侧悬浮按钮。
- 内容区：`.home-content`，最大宽度 1440。左右内边距为 64，屏幕宽度不到 1339px 时改为 48，不到 600px 时改为 24。
- 页面始终预留滚动条的位置（`scrollbar-gutter: stable`），避免页面因为出现或消失滚动条而左右跳动。

### 5. 响应式

目前没有统一的断点 token，以下是现有代码中实际使用的宽度：

| 宽度 | 用途 |
|---|---|
| 600px | 最常用，用于切换到手机布局 |
| 700 / 760 / 1000 / 1100 / 1120px | 各页面的网格从多列改为少列 |
| 1320 / 1339px | 筛选栏、外框的边距调整 |

每次改动后都要检查三个宽度：**桌面、390px、320px**，并且要看整页，不能只看改动的那一块。

## 二、卡片

### 1. 卡片悬停动效

- **基准**：`home-card-surface.tsx`（`HomeCardSurface`）和 `home-card-surface.css`。
- **效果**：卡片带有一点弹性。卡片入场时轻微摆动两下；鼠标悬停时，卡片会轻微跟随鼠标移动、上浮、倾斜，幅度控制在几像素和两三度以内。
- **三种模式**：
  - `regular`：首页活动卡。
  - `flat`：首页日常预览、官方活动月历。
  - `feed`：日常列表、成员、心愿、固定队、知识库、精选、公开分享、抽奖、后台入口。卡片越大，旋转幅度越小。
- **只在合适的设备上启用**：使用精细指针（如鼠标）、能悬停、并且用户没有开启"减少动态效果"。触屏设备和开启了减少动态的用户，卡片完全静止。
- **点击行为**：
  - 点击卡片空白处，跳转到卡片对应的页面。
  - 卡片内部的头像、链接、按钮、输入框各自独立响应，不会触发整卡跳转。需要独立响应的元素，加上 `data-home-card-independent`。
- **动效参数**都写在 `HOME_CARD_MOTION` 中。要调整动效，只改这一个地方。

### 2. 详情页卡片不加动效

- **基准**：`HomeCardNavigationSurface`（与上一节在同一个文件中）。
- 只保留"点击整张卡片跳转"，不加任何动效。用于心愿详情、我的活动等页面。
- **区分原则**：
  - 列表里的卡片：加动效。
  - 详情页里的信息卡片：保持静止。

### 3. 活动摘要卡

- **基准**：`home-activities.tsx`（`HomeActivityCard`）和 `home-activities.css`。首页、成员页的招募列表、心愿详情都在使用它。详情页使用时传入 `motion={false}`。
- **标题行**：左边是活动类型 Tag，右边是标题（24/34，可以换行），两者间距 8。标题是链接，平时不带下划线，悬停时变成主色。
- **信息行**：每行一个 20px 的图标加一行文字，超出部分用省略号截断。依次显示：期次、副本、地点、日期、人数。
- **时间**：14/22，次要文字颜色。
- **活动类型 Tag**：组件是 `activities/activity-type-tag.tsx`，使用实心 Tag。

  | 类型 | 颜色 |
  |---|---|
  | 普通单次 | 主色 |
  | 普通长期 | 危险色 |
  | 线下单次 | 信息色 |

- **首页活动网格**：三列，屏幕宽度不到 1120px 时改为两列，不到 760px 时改为一列。卡片内边距 24。

### 4. 活动详情信息卡

- **外壳**：`activities/activity-ui.tsx` 中的 `ActivityPaper`。
- **内容**：`activities/activity-detail-information.tsx`，固定分为五组，依次是：
  1. 基本信息
  2. 时间信息
  3. 期次
  4. 活动安排
  5. 参与要求
- 从第二组开始，每组上方有一条 1px 的分隔线，并留出 24 的间距。组标题为 16/26，标题颜色。
- 样式文件：`activities/activity-detail-refinement.css`。

### 5. 队伍构成与报名

- **席位面板**：`activities/activity-participation-panel.tsx`。
  - 每个席位是一个按钮，最小高度 110（精简版 132），职业图标 48×48。
  - 选中状态用 `aria-pressed` 标记。
  - 必须有禁用样式和键盘焦点样式。
- **报名和换位弹窗**：`activities/activity-registration-dialog.tsx`。
- **职业图标和名称**：`activity-ui.tsx` 中的 `RequirementIcon`、`requirementLabel`。

## 三、列表控件

下面这些共享组件都在 `collection-controls.tsx` 中，样式在 `collection-controls.css` 中。**新页面一律使用共享组件。**

### 1. 分类切换（Tabs）

- **组件**：`CollectionTabs`，带筛选栏时使用 `CollectionFilters`。
- **样式**：
  - 横线风格。标签文字 700 18/28（屏幕宽度不到 600px 时为 16/26），标题颜色，悬停时变成主色。
  - 标签之间间距 32（窄屏为 24）。
  - 底部是一条 1px 的浅色长线，选中的标签下方有一条 4px 粗的短线，居中对齐。
- **二级 Tabs**：使用 `variant='secondary'`，不画底部长线。
- **注意**：共享 Tabs 的字体样式只在 `.home-content` 里面生效。如果放在弹窗等 `.home-content` 外面的地方，需要另外补充样式。

### 2. 搜索框

- **组件**：`CollectionSearch`，基于 AntD `Input.Search`。
- **行为**：
  - 关闭浏览器的自动填充，最多输入 100 字。
  - 右侧的清除按钮是一个 24×24 的"×"。点击后同时清空输入框和当前的搜索条件，并回到第一页。
- **宽度**：默认最宽 360，最窄 220。屏幕宽度不到 1320px 时为 300；不到 1000px 时换到下一行并靠右；不到 600px 时占满整行。

### 3. 分页

- **组件**：
  - `ListPagination`：已知总页数时使用。
  - `CursorPagination`：只知道"还有没有下一页"时使用，只显示当前页码。
  - `PageArrowButton`：单独的翻页箭头按钮。
- **样式**：
  - 中间显示"当前页 / 总页数"（700 24/40），左右各有一个 44×44 的箭头按钮。
  - 按钮没有边框、没有背景、没有阴影，悬停时变成主色。禁用时为次要文字颜色，透明度 0.35。必须保留键盘焦点样式。
  - 箭头和页码的间距为 24（窄屏为 18），与上方内容的间距为 24。
- **只有一页时不显示分页。**
- **翻页定位**：翻页后，页面会尽量让分页控件停留在原来的屏幕位置，不会突然跳回顶部（`pagination-viewport.ts`）。

### 4. 评论区

- **组件**：`discussion-comments.tsx`（`DiscussionComments`）。日常、相册、心愿共用这一个组件。
- 支持楼中楼、带图片、@ 提及、表情，评论列表自带分页。

## 四、菜单、确认与危险操作

### 1. 操作菜单（三角菜单）

- **组件**：`operation-menu.tsx`（`OperationMenu`）和 `operation-menu.css`。
- **触发**：右上角一个 32×32 的小三角按钮。鼠标悬停或点击都能打开菜单，触屏设备点击打开。
- **菜单外观**：
  - 浅色弹层，带圆角和阴影。
  - 宽度在 152 到 320 之间，内边距 8。
  - 菜单项是透明背景的按钮，悬停时显示浅色底。
- **键盘操作**：
  - 方向键、Home、End 用来在菜单项之间切换。
  - Esc 关闭菜单，焦点回到触发按钮。
- **点击菜单不会触发外层卡片的跳转。**
- **菜单项顺序**：普通操作在前，删除在后，"违规删除"永远放在最后一项。

### 2. 确认弹窗

- **普通确认**：使用 `ui/paper-modal.tsx`（`PaperModal`）。弹窗居中显示，使用纸张风格的关闭图标。
- **违规删除**：使用 `content-moderation-dialog.tsx`。弹窗内必须填写理由，并二次确认。
- **会扣分或不可恢复的操作**：必须在确认弹窗里写清楚后果，比如"将记 2 点"、"删除后不可恢复"。

### 3. 危险与警示按钮

| 语义 | 用途 | 样式 |
|---|---|---|
| 危险 | 删除、取消活动、违规删除 | AntD `Button` 加 `danger`，颜色取 `colorError`（#A34335），**去掉阴影** |
| 警示 | 有后果但可以撤回的操作，例如撤销管理员 | 文字和边框为 #79561A，悬停时底色 #F8EDCE |

- 危险和警示是两种语义，不要混用颜色，也不要改变按钮原来的形态（实心、描边、文字按钮）。
- 不要额外添加阴影、描边或渐变。
- 保留键盘焦点样式。

## 五、反馈与状态

### 1. 操作结果提示（浮动消息）

- **组件**：`use-feedback-message.ts`。使用的组件必须挂载它返回的 `contextHolder`。
- **位置和时长**：显示在页面顶部居中，距顶部 24，持续 5 秒，鼠标悬停时不会暂停计时，点击后立即关闭。
- **外观**：宽 280，最小高度 48，圆角 12，带 1px 的语义色边框。

  | 语义 | 背景 | 文字 |
  |---|---|---|
  | 成功 | #E5EEDB | #326846 |
  | 失败 | #F7E4DC | #A34335 |
  | 警示 | #F8EDCE | #79561A |
  | 信息 | #E4EEEC | #315F67 |

- **例外**：带操作链接的提示（例如"已保存，去查看"）不会自动消失，需要用户手动关闭。
- **跨页面的提示**：比如保存后跳转到另一个页面再显示提示，使用 `activities/activity-edit-feedback.tsx`。

### 2. 三种反馈的分工

| 场景 | 用什么 |
|---|---|
| 一次操作的结果（保存成功、报名失败等） | 浮动消息 |
| 页面数据加载失败、需要一直显示的错误 | `account/account-ui.tsx` 中的 `ErrorNotice` |
| 进入页面就要知道的门槛说明（例如"仅正式成员可以发布"） | AntD `Alert` |

### 3. 加载与等待

- **全局等待条**：用户操作进行中时，页面顶部显示一条进度条（`global-interaction.css`、`user-operation-provider.tsx`）。开启"减少动态效果"的用户看到的是静止的满宽条。
- 按钮、搜索框、下拉框**不显示旋转的加载图标**，统一由顶部进度条表示等待状态。
- 禁用状态的鼠标光标统一为默认箭头，不使用"禁止"图标。
- 每个列表都要有三种状态：加载中、空数据、出错。

### 4. 时间显示

- 时间一律按北京时间显示，工具函数在 `packages/domain` 的 `beijing-time` 中。
- **我的活动卡片**：日期分两行显示。
  - 第一行：月日，22/30，加粗，标题颜色。
  - 第二行：`HH:mm - HH:mm`，14/22，次要文字颜色。
- **实时时钟组件**：`activities/beijing-clock.tsx`。这个组件目前**没有任何页面在用**。需要显示当前北京时间时，使用这个组件。

## 六、表单与输入

- 浏览器自动填充统一关闭（`browser-input-policy.tsx`）。只有手机号、当前密码、新密码这三个字段保留自动填充。
- 输入框、下拉框、日期选择器的焦点样式统一处理，区分鼠标点击和键盘切换两种情况（`control-focus-provider.tsx`）。
- 日期选择器使用中文界面（在 `providers.tsx` 中设置）。

---

## 七、文案

- 页面上只保留操作必需的文字：提示、确认、校验信息、错误原因、处罚说明。
- **不要**在页面上写实现范围、开发进度、"本功能暂不支持某某"这类说明。
- 错误提示要说清楚两件事：发生了什么，用户该怎么做。

---

## 八、无障碍

- 只有图标的按钮必须加 `aria-label`。
- 不要去掉键盘焦点样式。全站统一使用 2px 主色描边，向外偏移 3px。
- 纯装饰用的图片，设置 `alt=""` 和 `aria-hidden`。
- 可以点击的卡片，必须同时提供一个等效的链接或按钮，保证键盘也能操作。
- 动效必须尊重系统的"减少动态效果"设置。
