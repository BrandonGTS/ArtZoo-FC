## 维护约定

- **只写现在的状态**：文档描述的是代码当前的行为和当前的规则。历史过程、验收记录、执行证据都不写进来，需要追溯时看 git 提交记录，或者去只读的旧仓库查。
- **文档和代码对不上时**：不要自己判断哪边是对的，先报告给站长，由站长决定改文档还是改代码。
- **每份文档不超过 100 KB**：超过这个大小，CI 会报错。
