# 给 AI 的任务模板

给 Codex 布置任务时，复制下面的模板，填好后发给它。一个任务只做一件事，每个任务开一个新会话。

---

```text
【背景】
这是 ArtZoo 新仓库。先读根目录 AGENTS.md，以及本次涉及目录里的 AGENTS.md。

【目标】
（一句话说明要达到什么效果，例如：活动详情页的报名按钮，在截止后改为灰色并显示"已截止"。）

【范围】
可以改：（列出文件或目录，例如 apps/web/components/activities/）
不要改：（例如：不改后端接口，不改数据库）

【参考】
（相关的规则文档、页面地址、截图，或者 docs/DECISIONS.md 里的第几条。）

【验收】
- 怎样才算完成：（例如：截止后按钮为灰色、点击没有反应；截止前的行为不变。）
- 需要的测试：（例如：补一条"截止后报名被拒绝"的测试。）
- 视觉改动先给我看修改前后的对比，我确认后再提交。

【交付】
在新分支上完成，然后告诉我：
1. 改了哪些文件；
2. 我要运行哪些命令来验证，包括 node scripts/check-rules.mjs --base origin/main；
3. 有哪些没做，或者没验证的地方。
```

---

## 什么时候需要先要设计说明

遇到下面任何一种情况，先让 AI 只写设计说明，不改代码。你同意之后，再让它动手：

- 新增一个功能模块或子系统；
- 预计新增超过 1000 行代码；
- 改动数据库结构；
- 改动登录、权限、短信、限流相关的逻辑；
- 新增依赖。
