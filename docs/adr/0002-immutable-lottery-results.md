# ADR-0002：固定开奖资格时刻并保留不可变结果

日期：2026-11-05

状态：现状记录（源码基线 `1df5504`；未新增用户决策）

## 背景与现行选择

后台调度可能晚于设定开奖时刻，账号身份/启停和签到也会变化。现有系统使用[抽奖资格历史事实](../../packages/db/prisma/migrations/20261019163000_lottery_eligibility/migration.sql)，由[资格端口](../../packages/db/src/lottery-eligibility.ts) 读取规定时刻的完整资格。维护拒绝不完整或时刻不匹配的快照，不把处理时刻账号当前状态直接当开奖时刻状态。

[LotteryMaintenance](../../packages/db/src/lottery-maintenance.ts) 在事务内确定参与者并写一次结果；非 OPEN 状态返回已有结果。SQL 的 [Lottery_immutable 触发器](../../packages/db/prisma/migrations/20261019160000_lottery/migration.sql) 保护已发布参数及终态结果。现有代码先提交结果，再幂等构造通知；通知构造失败不能让一次抽取回滚后重抽。

## 后果与保护

资格事实和结果需要长期保留，补跑不能凭后来身份改写历史。AUTO 纳入仍保留显式退出，不能因性能优化重新报名 opt-out 账号。通知 eventKey 保证构造幂等，但不等于外部供应商已经送达。

改变时间、资格历史、排序、锁或通知构造边界会影响公平性与一致性，必须按业务高风险验证。不能以“只优化查询”为由删历史事实、改截止或允许已开奖结果编辑。本文不授权修历史开奖或补通知。

## 验证依据与局限

依据当前 SQL、资格及维护源码；已有发布与验证边界见[固定发布回执](../rev1105-production.md)。本次为文档核验，没有真实开奖、数据库连接或新的并发测试，也没有宣称所有剩余抽奖性能审查项通过。
